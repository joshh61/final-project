# Campus Vibes — Flutter Campus Event App

## What This Is
A Flutter mobile app for discovering UTRGV campus events on an interactive Mapbox map with GPS walking navigation. Senior project for CSCI 4390, Spring 2026.

## Tech Stack
- **Framework**: Flutter 3.41.x / Dart 3.11
- **Map**: Mapbox Maps SDK (`mapbox_maps_flutter`) + Mapbox Directions API
- **Backend**: Firebase (Core, Cloud Firestore, Firebase Auth)
- **GPS**: `geolocator` package
- **HTTP**: `http` package for API calls
- **Platform**: iOS only (mapbox_maps_flutter does NOT support web)

## Project Structure
```
lib/
  main.dart              — App entry, auth gate, MapScreen
  home_screen.dart       — Bottom nav bar (Events list / Map toggle)
  event_screen.dart      — Scrollable event list with Firestore stream
  login_screen.dart      — Email/password login/signup
  live_navigation.dart   — GPS walking directions with route shrinking
  models/
    event.dart           — Event class (toMap/fromFirestore)
  services/
    firestore_service.dart — addEvent, getEventsStream, deleteEvent
    auth_service.dart      — signUp, signIn, signOut
  firebase_options.dart  — Generated by FlutterFire CLI (don't edit manually)
```

## Key Commands
- `flutter run -d "iPhone 16e"` — Run on iOS Simulator
- `flutter run` — Run on connected device
- `dart analyze lib/` — Check for errors
- `flutter pub get` — Install dependencies
- Boot simulator: `xcrun simctl boot "iPhone 16e" && open -a Simulator`

## Important Constraints
- iOS deployment target: 15.0 (required by Firebase)
- Mapbox access token is hard-coded in main.dart (needs --dart-define eventually)
- `mapbox_maps_flutter` does NOT compile for web — never attempt `flutter run -d chrome`
- Colors.blue.value is deprecated — use Colors.blue.toARGB32() instead
- Bundle ID: com.jraudy.finalProject
